# 🎬 Cinemate AI
An AI-powered movie recommendation and seat reservation backend engine built in Java.

## 🚀 Features
* **AI Movie Concierge:** Natural language query matching for discovering movies by genre, title, or synopsis.
* **Concurrency-Safe Seat Manager:** Prevents double-booking race conditions during high-demand reservations.
* **Object-Oriented Architecture:** Clean separation of concerns using model and service layers.

## 🛠️ Tech Stack
* **Language:** Java
* **Build Tool:** Maven
* **Paradigms:** Object-Oriented Programming, Collections API, Stream API
